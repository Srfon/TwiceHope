# STS3032 サーボ制御ライブラリ 仕様書

`servo_cli.py` の仕様をまとめたドキュメントです。FEETECH STS3032 シリアルサーボを 4 つの動作モードで制御でき、モード・回数・移動量などを関数引数またはコマンドライン引数で指定できます。

---

## 1. 概要

| 項目 | 内容 |
|---|---|
| 対象サーボ | FEETECH STS3032(STS シリーズ互換) |
| 通信方式 | 半二重シリアル(FEETECH/STS プロトコル) |
| 既定ポート | `/dev/ttyUSB0` |
| 既定ボーレート | `1000000` bps |
| タイムアウト | `0.03` 秒 |
| 主なクラス | `STSBus` |
| 簡易実行関数 | `servo_move(mode, repeat, amount, speed, ...)` |

特徴は、(1) 動作モードを引数 1 つで切り替えられること、(2) サーボモードを相対(積算)で動かせること、(3) 4096 を超えたときの挙動を選べること、の 3 点です。

---

## 2. 動作モード

動作モードはサーボの WorkMode レジスタ(アドレス 33)で決まり、`mode` 引数で指定します。

| mode | 定数 | 種類 | 制御に使うレジスタ |
|---|---|---|---|
| 0 | `MODE_SERVO` | サーボ(位置) | Goal Position (42), 0〜4095 |
| 1 | `MODE_SPEED` | 連続回転・速度 | Goal Speed (46), ±10〜9999 |
| 2 | `MODE_TORQUE` | 連続回転・トルク | addr 41, Time ±50〜1000 |
| 3 | `MODE_STEP` | ステップ(移動量) | Goal Position (42), ±30719 |

### 各モードでの引数の意味

`servo_move(mode, repeat, amount, speed)` の `amount` と `speed` はモードで意味が変わります。

| mode | `amount`(第3引数) | `speed`(第4引数) | `repeat`(第2引数) |
|---|---|---|---|
| 0 サーボ | 目標位置を相対加算(0〜4095) | 動く速さ | 回数ぶん積算。4096で頭打ち |
| 1 速度 | 回転速度(±、負で逆回転) | 無視 | 同じ速度を再送するだけ |
| 2 トルク | トルク/Time値(±、負で逆回転) | 無視 | 同じ値を再送するだけ |
| 3 ステップ | 1回あたりの移動量(相対) | 動く速さ | 回数ぶん累計(±30719まで) |

### モードごとの説明

**モード0:サーボ(位置)** は指定角度へ動きます。相対積算が既定なので、1000 を繰り返すと 1000 → 2000 → 3000 と進みます。1 回転(0〜4095)が物理的な上限で、それ以上は動けません。角度決めや 1 回転以内の往復に向きます。

**モード1:速度(連続回転)** はモーターのように回り続けます。`amount` が回転速度で、負の値で逆回転します。位置の概念がないため、停止するには速度 0 を送ります。

**モード2:トルク(連続回転)** はトルク(押す力)を指定して回します。`amount` が Time 値(目安 ±50〜1000)で、負の値で逆回転、0 で停止します。※書き込みアドレス(41)は参考記事の実測値に基づくため、実機での確認を推奨します。

**モード3:ステップ** は「指定量だけ回す」を多回転で行えます。4096 の壁がなく、累計 ±30719(約 7.5 回転)まで相対で回り続けます。連続的に相対回転させたい場合の推奨モードです。

---

## 3. 4096 を超えたときの挙動(重要)

サーボモード(mode 0)はハードウェア的に 1 回転(0〜4095)しか扱えません。相対積算で内部目標がこの範囲を超えると、以降は動かなくなります。本ライブラリでは以下の 3 通りで対処します。

| 対処 | 設定 | 挙動 |
|---|---|---|
| 警告して頭打ち(既定) | `wrap=False` | 4095 で止まり、警告メッセージを表示 |
| 周回 | `wrap=True` | 0〜4095 を巻き戻して回り続ける(継ぎ目で逆方向に戻る) |
| 多回転モードに変更 | `mode=3` | ステップモードで連続回転(±30719 まで) |

連続して何回転も動かしたい場合は **mode=3(ステップ)** が本来の解決策です。`wrap=True` はサーボの構造上、継ぎ目で大きく戻る動きになるため応急処置という位置づけです。ステップモードも累計が ±30719 を超える手前で警告し、範囲内に収まる分だけ動かして停止します。

## 4. 簡易実行関数 `servo_move`

```python
servo_move(mode, repeat=1, amount=1000, speed=200,
           interval=2.0, ids=None, port="/dev/ttyUSB0",
           relative=True, wrap=False)
```

| 引数 | 既定 | 説明 |
|---|---|---|
| `mode` | (必須) | 動作モード 0〜3 |
| `repeat` | 1 | 何回動かすか |
| `amount` | 1000 | 1回あたりの移動量/速度/トルク |
| `speed` | 200 | 速度(mode 0/3 用) |
| `interval` | 2.0 | 1回ごとの待ち時間(秒) |
| `ids` | None | 動かすID。None なら自動スキャンの全ID。例 `[1, 2, 3]` |
| `port` | `/dev/ttyUSB0` | シリアルポート |
| `relative` | True | サーボモードを相対(積算)にするか |
| `wrap` | False | サーボモードで 4095 超えを周回させるか |

使用例:

```python
servo_move(0, 3)                 # サーボを3回(1000→2000→3000)
servo_move(3, 6, 1000, 2500)     # ステップを6回・移動量1000・速度2500(累計6000)
servo_move(1, 1, 2000)           # 速度2000で連続回転
servo_move(1, 1, 0)              # 停止
servo_move(0, 3, ids=[1, 2])     # ID指定
servo_move(0, 10, wrap=True)     # サーボのまま周回
```

## 5. コマンドライン実行

引数の並びは `モード 回数 [移動量] [速度]` です。

```bash
python servo_cli.py 0 3              # mode=0 を 3回
python servo_cli.py 0 5 500 300      # mode=0, 5回, 移動量500, 速度300
python servo_cli.py 3 2 4096         # ステップ, 2回, 4096
python servo_cli.py 0 3 --ids 1 2    # ID指定
```

| オプション | 説明 |
|---|---|
| `--port` | シリアルポート(既定 `/dev/ttyUSB0`) |
| `--interval` | 1回ごとの待ち時間(秒) |
| `--ids` | 動かすID(省略時は自動スキャン) |
| `--no-relative` | サーボモードを絶対値で動かす |
| `--wrap` | サーボモードで 4095 超えを周回させる |

引数なしで実行(VSCode の実行ボタンなど)した場合は、ファイル先頭の設定ブロック(`MODE` / `REPEAT` / `AMOUNT` ...)の値で動作します。

## 6. クラス `STSBus`

```python
STSBus(port="/dev/ttyUSB0", baudrate=1000000, timeout=0.03,
       mode=MODE_SERVO, ids=None, auto_scan=True,
       servo_relative=True, servo_wrap=False)
```

### 主なメソッド

| メソッド | 説明 |
|---|---|
| `ping(sid)` | サーボの応答確認 |
| `scan_ids()` | 接続中のサーボIDを探索 |
| `set_mode(sid, mode)` | 動作モードを変更(現在値と同じなら書込まない) |
| `set_mode_all(mode)` | 全サーボの動作モードを変更 |
| `move(sid, value, speed, time_ms, mode, relative, repeat, interval)` | 1台を動かす(モードで挙動が変わる) |
| `move_group(targets, mode, relative, repeat, interval)` | 複数台を同時に動かす(SYNC WRITE) |
| `get_position(sid)` | 現在位置を取得 |
| `get_mode(sid)` | 現在の動作モードを取得 |
| `set_origin(sid, value)` | 相対動作の基準(内部目標位置)を設定 |
| `torque_on(sid)` / `torque_off(sid)` | トルクの ON/OFF |
| `close()` | シリアルポートを閉じる |

### `move_group` の入力形式

```python
bus.move_group({
    1: {"position": 1000, "speed": 200},
    2: {"position": 1000, "speed": 200},
}, repeat=3, interval=2)
```

キーはモードによって変わります。mode 0/3 は `position`(+ `speed`, `time`)、mode 1 は `speed`、mode 2 は `torque` を使います。

## 7. レジスタマップ(使用アドレス)

| アドレス | 名称 | 領域 | 用途 |
|---|---|---|---|
| 33 | WorkMode | EEPROM | 動作モード |
| 40 | Torque Enable | SRAM | トルク ON/OFF |
| 41 | Goal Acceleration | SRAM | mode2 のトルク/PWM(実測) |
| 42 | Goal Position | SRAM | mode0:目標位置 / mode3:移動量 |
| 44 | Goal Time | SRAM | 移動時間 |
| 46 | Goal Speed | SRAM | mode1:速度 / mode3:速度 |
| 55 | Lock | EEPROM | EEPROM ロック(0=解除, 1=ロック) |
| 56 | Present Position | SRAM | 現在位置 |
| 62 | Present Voltage | SRAM | 電圧 |
| 63 | Present Temperature | SRAM | 温度 |

EEPROM 領域(33 など)への書き込みは、ロック解除(55 へ 0)→ 書き込み → 再ロック(55 へ 1)の手順で行います。EEPROM の書き換え回数には上限があるため、`set_mode` は現在値と同じ場合は書き込みません。

## 8. 通信プロトコル

| 項目 | 内容 |
|---|---|
| ヘッダ | `0xFF 0xFF` |
| パケット構成 | `FF FF [ID] [LENGTH] [INST] [PARAMS...] [CHECKSUM]` |
| チェックサム | `(~sum(ID以降LENGTH含む〜PARAMS)) & 0xFF` |
| 一斉指令ID | `0xFE`(SYNC WRITE で使用) |

インストラクション: PING=0x01, READ=0x02, WRITE=0x03, SYNC WRITE=0x83。

### 符号付き値のエンコード

mode 1/2/3 の符号付き値は、bit15 を符号ビット、下位 15bit を大きさとする符号絶対値形式で送ります(負の値は `|0x8000`)。

---

## 9. 注意事項

- ステップモードの目標値が「移動量(相対)」か「絶対位置」かは参考記事の記述に基づく実装です。`servo_move(3, 3, 1000)` を流して累計 3000 ぶん回るか実機で確認してください。1000 の位置で止まる場合は絶対指定のため、送信値を累計に変える対応が必要です。
- mode 2(トルク)の書き込みアドレス 41 は参考記事の実測値です。実機で挙動を確認してください。
- サーボモードは 1 回転(0〜4095)が上限です。多回転はステップモード(mode 3)を使用してください。
- `interval` は移動が完了する前に次の指令が来ないよう、動作時間に応じて十分な秒数を設定してください。
