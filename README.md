# TwiceHope

**RoboCup Rescue Maze — Autonomous Robot Development**

TwiceHopeは、RoboCup Rescue Mazeに取り組むロボット開発チームです。

限られた時間の中で迷路を探索し、障害物や段差を越えながら被災者を発見・救助する自律走行ロボットを開発しています。機体の設計からセンサー制御、経路探索、画像認識まで、実機での試験と改良を重ねています。

現在は2027年大会に向けて、走行の安定性と探索精度の向上に取り組んでいます。

## 開発内容

### 自律探索・マッピング
LiDARで周囲の壁や障害物を検出し、走行しながら迷路の地図を生成します。未探索エリアへの移動、現在位置の補正、スタート地点への帰還を含む探索アルゴリズムを開発しています。

### 被災者認識
USBカメラの映像から、H・S・Uの文字や色で示された被災者を識別します。照明や撮影角度の違いにも対応できるよう、画像処理と機械学習の両面から検証を進めています。

### 走行・姿勢制御
モーター制御と各種センサーを組み合わせ、タイル間の移動や旋回時の姿勢補正を行います。傾斜路、段差、バンプなど、平坦でないコースでの走破性も重要な開発テーマです。

### 表示・デバッグ
探索状況やセンサーデータを確認するため、Web画面と小型LCDを利用した表示・ログ管理を整備しています。

## 使用技術

| 分野 | 主な機器・技術 |
| --- | --- |
| メインコンピューター | Raspberry Pi 5 |
| 距離計測 | RPLIDAR A1M8、ToFセンサー |
| 画像認識 | USBカメラ、OpenCV、MobileNetV3 |
| 姿勢・走行 | IMU、モーター制御（STS3215関連の開発・検証） |
| 表示・通信 | Python、FastAPI、UART、LCD |

センサー構成や制御方式は、開発段階に応じて見直しています。

## リポジトリ構成

実機の開発ディレクトリ `RobCup_V3` を基に、用途ごとにファイルを整理しています。

```text
TwiceHope/
├── Code/
│   ├── Display_Process/     # LCD表示・ログ関連
│   ├── Lidar_viwer/         # LiDARの計測・可視化テスト
│   ├── MobileNetV3_1/       # 画像認識モデルの学習・推論
│   ├── RoboCup_Maze_World/  # センサー・モーター・状態・マップ
│   ├── sts3215/            # 走行・探索・マッピング
│   ├── src/                # 制御プログラムと各種実験
│   ├── sensors_test/       # センサーの動作確認
│   ├── imu_test/           # IMUの計測・補正テスト
│   ├── camera_test/        # カメラ関連のテスト
│   └── test/               # 統合・走行テスト
└── docs/                   # 開発資料
```

## 2027年に向けて

特に次の課題を重点的に改善しています。

- 傾斜路やバンプを含むコースでの安定走行
- 旋回後の位置・角度補正と走行停止の不具合解消
- LiDARを利用した地図生成・経路選択の精度向上
- 被災者の文字・色認識の安定化
