# TwiceHope システム構成（設計メモ）

## ハードウェア
- Raspberry Pi 5: RPLIDAR A1M8、左右USBカメラ、迷路地図、探索経路、Web/LCD画面
- SPIKE Prime: 走行モーター、キット投下モーター、カラーセンサー、フォースセンサー
- Raspberry Pi ↔ SPIKE Prime: UART（コマンド形式・配線は実機コードに合わせて確定）

## 既存コードの配置先
- `sts3215/robot_mapping5.py`: 地図生成・探索等
- `Display_Process/display_manager5.py`: LCD/表示管理等
- `Display_Process/Log/Logger5.py`: ログ管理等
- `Lidar_viwer/`: LiDAR検証コード（実機と同じスペル）
- `RoboCup_Maze_World/`: センサー・モーター・状態・マップの各モジュール
- `MobileNetV3_1/`: 画像認識の学習・推論関連
- `spike/`: GitHub上の将来用フォルダー。実機の提供一覧にはなし

これらはユーザー提供の実機ファイル一覧から確認したパスです。GitHubにはまだ実装本体を登録していません。

[実機の全ファイル一覧](raspi5-file-tree.md) を参照してください。

## マッピングと探索（現行方針）
- タイル: 30 × 30 cm
- マップ属性: 通常0、被災者1、通行不可2、チェック3、危険4、バンプ5、障害物6、段差7、坂8
- 被災者分類: H / S / U、赤 / 黄 / 緑
- 優先: 隣接する未到達タイルを優先し、基本方向は前進 → 左 → 右 → Uターン
- 地図の更新: ロボット停止時を基本とする
- 全マスの把握後は開始地点 (0, 0) に帰還する

## 表示系
- Web表示: FastAPI（既存構成ではポート8000）
- LCD: ST7789とPNGミラー
- ログ例: `/home/trin1/RobCup_V3/Display_Process/Log/system.log`
- 表示用ソケット例: `/tmp/display.sock`

## 2027年に向けた優先課題
1. 傾斜路・バンプの通過安定性
2. Uターン後やタイル動作後の停止不具合の調査
3. ジャイロ補正・LiDARによる中心位置補正
4. 被災者認識と色判別の精度検証

## 安全な導入手順
実機からバックアップを確保し、ソースコードを確認してからアップロードする。モーターを動かす変更は、車輪を浮かせた状態でテストしてから床面で確認する。
